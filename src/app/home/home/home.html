Proyecto Angular

Página interactiva con routing, Bootstrap y buenas prácticas de organización del código.

Arquitectura y diseño

La página fue desarrollada en Angular utilizando varios componentes conectados mediante routing para poder navegar desde un menú principal hacia cada sección. Se utilizó Bootstrap para el diseño visual, logrando una interfaz moderna y responsive.

Datos y directivas

En la aplicación se trabajó con arrays de objetos para almacenar información dinámica como actividades, productos y cartas del juego. Estos datos se mostraron en pantalla utilizando directivas de Angular como ngFor y ngIf.

Interacción

También se implementaron eventos y binding para permitir la interacción del usuario, por ejemplo botones para avanzar slides, agregar elementos al carrito, iniciar juegos y registrar información desde formularios.

Formularios y pipes

Se utilizaron formularios para cargar datos y realizar cálculos automáticos según opciones seleccionadas por el usuario. Además, se aplicaron pipes para formatear fechas y precios.

Modales y servicios

La aplicación incorporó modales de Bootstrap para mostrar información emergente como el carrito de compras. También se trabajó con servicios de Angular para gestionar datos mediante operaciones CRUD, separando la lógica de la interfaz.

Resumen

En general, el proyecto combinó Angular, TypeScript, HTML, CSS y Bootstrap para crear una página interactiva, dinámica y organizada, enfocada en actividades, registros y manejo de información en tiempo real.
